# Stage — медиасервис-тизер

Сайт-тизер Stage: лендинг со сбором почты, страница «О проекте», темы (категории) и материалы (статьи, упражнения, программы), админка для контента и медиа, сиды и API только на чтение для мини-приложения VK.

Stage — это wellness, не медицина: в контенте нет диагнозов, дозировок и обещаний лечения.

## Запуск

Нужен Ruby 3.3 (см. `.ruby-version`). Rails 8.1 и SQLite.

```sh
bundle install
bin/rails db:prepare db:seed   # 4 темы, 20 материалов, 3 тестовые подписчицы
bin/dev                        # http://localhost:3000
bin/rails test                 # модели, страницы, админка, API, CORS
```

Сиды идемпотентны: их можно запускать повторно.

## Разделы

| Адрес | Что там |
|---|---|
| `/` | Лендинг: hero, форма подписки, пример «слоя дня», темы, программы, знания |
| `/about` | О проекте |
| `/feed?section=knowledge\|discussions` | Лента: фильтр Все / Знания / Обсуждения. Знания — программы, упражнения, статьи; обсуждения — круги и свежий пост |
| `/circles/:slug` | Круг (обсуждение по теме) и его посты |
| `/categories`, `/categories/:slug` | Темы и материалы темы, фильтр `?kind=exercise` |
| `/posts`, `/posts/:slug` | Все материалы и страница материала (видео или обложка, текст, похожие) |
| `/admin` | Админка (HTTP Basic) |
| `/api/v1/...` | API для VK |
| `/up` | Health check |

## Админка

В админке можно:
- создавать, редактировать и удалять темы и материалы;
- загружать обложки через Active Storage или указывать внешний URL;
- добавлять видео по ссылке на YouTube или VK;
- публиковать материалы и откладывать публикацию по `published_at`;
- смотреть список подписчиц и выгружать его в CSV.

Доступ настраивается через переменные окружения:

```sh
ADMIN_USER=... ADMIN_PASSWORD=...
```

В development без них работает `admin` / `stage`. В production без этих переменных админка отвечает 503, пароля по умолчанию там нет.

Тему, в которой есть материалы, удалить нельзя (`restrict_with_error`): контент не теряется случайно.

## API для мини-приложения VK

API только на чтение, в формате JSON. Методы: GET, HEAD, OPTIONS. Черновики и материалы с будущей датой публикации в ответ не попадают.

| Запрос | Ответ |
|---|---|
| `GET /api/v1/categories` | Темы с `posts_count` |
| `GET /api/v1/categories/:slug?kind=` | Тема и её материалы |
| `GET /api/v1/posts?category=&kind=&page=&per_page=` | Материалы, `meta: {page, per_page, total, total_pages}`, `per_page` от 1 до 50 |
| `GET /api/v1/posts/:slug` | Материал целиком, включая `body` |

Ссылки на медиа в ответах абсолютные: `cover_url`, `video_url` и `web_url`, то есть ссылка на страницу сайта.

Если ресурс не найден, API отвечает `404 {"error":"not_found"}`.

CORS: разрешённые домены задаются в `CORS_ORIGINS`, через запятую. Например:

```sh
CORS_ORIGINS=https://vk.com,https://*.vk-apps.com
```
